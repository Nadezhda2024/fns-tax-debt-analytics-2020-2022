# Анализ налоговой задолженности в Российской Федерации (2020–2022 гг.)

Аналитическое исследование динамики, структуры и качества взыскания налоговой задолженности в Российской Федерации на основе открытых государственных данных ФНС России и портала «Электронный бюджет». Итоговый отчет собран в виде автономной интерактивной HTML-страницы без внешних зависимостей.

## Описание задачи

Цель исследования — оценить масштабы и ключевые драйверы роста налоговой задолженности в РФ за три полных отчетных года (2020–2022 гг.), выявить структурные аномалии по видам налогов и статусам взыскания, а также сформировать практические рекомендации по повышению эффективности урегулирования долга.

В ходе работы решены следующие задачи:
* Собраны и унифицированы сводные данные Раздела 8 Сводного налогового паспорта РФ по состоянию на 01.01.2021, 01.01.2022 и 01.01.2023.
* Выполнена перекрестная макроэкономическая сверка задолженности с фактическими доходами консолидированного бюджета РФ через API Единого портала бюджетной системы «Электронный бюджет».
* Рассчитаны абсолютные и относительные темпы прироста, удельный вес категорий в общем долге и распределение по статусам взыскания.
* Построены деловые аналитические диаграммы и сформулированы 4 прикладные меры по повышению собираемости платежей с привязкой к нормативной базе РФ.

## Стек технологий и применение AI-агентов

Проект реализован как гибридный аналитико-инженерный конвейер с разделением задач между Python-библиотеками и AI-инструментами:

* **Python (Pandas, Requests, Matplotlib, OpenPyXL, Python-dotenv):**
  * `requests` и `python-dotenv` — подключение к REST API портала «Электронный бюджет», фильтрация по кодам бюджетной классификации (КБК) и загрузка доходов консолидированного бюджета РФ.
  * `pandas` и `openpyxl` — аудит структуры отчётных форм ФНС, нормализация колонок за 2020–2022 годы, объединение источников в единый плоский датасет `passport_debt_rf_2020_2022.csv`, расчет темпов прироста и структурных долей.
  * `matplotlib` — генерация диаграмм в единой монохромной финансовой палитре и кодирование графиков в строки `base64` для встраивания в автономный отчет.
* **Gemini 3 Pro (Google AI Mode в браузере):**
  * Поиск и верификация открытых наборов данных ФНС и Минфина, сверка нормативно-правовой базы (Постановления Правительства РФ № 409 и № 497), интерпретация аномалий (в частности, скачка недоимки по НДПИ и влияния моратория на банкротство) и формулирование управленческих гипотез.
* **GitHub Copilot (встроенный агент в VS Code):**
  * Помощь в проектировании адаптивного макета отчета и сборка итогового самодостаточного HTML-файла.

## Ключевые аналитические выводы

1. **Ускорение роста долга:** за 2020–2022 годы совокупная налоговая задолженность в РФ (с учетом страховых взносов) увеличилась на 38,1% (+697,64 млрд руб.) — с 1,83 трлн руб. до 2,53 трлн руб. Основной прирост (+27,1%) пришёлся на 2022 год. Отношение долга к доходам консолидированного бюджета РФ выросло с 14,57% в 2021 году до 16,38% в 2022 году.
2. **Сдвиг в сторону неурегулированной недоимки:** доля неурегулированной недоимки с пенями и санкциями в общем долге выросла с 49,7% в 2020 году до 64,7% в 2022 году (до 1 636,83 млрд руб.).
3. **Главные драйверы и аномалии:**
   * **НДС и налог на прибыль:** задолженность по НДС выросла на 50,2% (до 725,43 млрд руб., доля 28,7% в общем долге), а долг по налогу на прибыль организаций увеличился более чем вдвое — на 114,0% (до 320,37 млрд руб.).
   * **Аномальный скачок НДПИ:** задолженность по налогу на добычу полезных ископаемых выросла на 372,5% (в 4,7 раза — с 24,26 до 114,60 млрд руб., в том числе +227,1% в 2022 году) на фоне разовых изъятий в сырьевом секторе и перестройки экспортных потоков.
   * **Влияние антикризисных мер:** пик отсроченных платежей в 2020 году (137,36 млрд руб.) связан с действием Постановления Правительства РФ № 409, а рост приостановленной к взысканию задолженности в 2022 году до 927,23 млрд руб. (+19,3%) обусловлен мораторием на банкротство по Постановлению Правительства РФ № 497.
4. **Положительная динамика по взносам:** задолженность по страховым взносам за три года снизилась на 12,8% (с 360,93 до 314,67 млрд руб.), а её доля в совокупном долге сократилась с 19,7% до 12,4%.

## Инструкция по запуску

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <URL_вашего_репозитория>
   cd <папка_проекта>
   ```
2. Создайте и активируйте виртуальное окружение, затем установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Для повторного обращения к API «Электронного бюджета» создайте в корне проекта файл `.env` и укажите в нем базовый адрес набора данных `7710568760-REPEXECUTINCOMEKBRF`:
   ```env
   BUDGET_API_URL=https://budget.gov.ru
   ```
4. Пересоберите графики и итоговый отчет:
   ```bash
   python scr/build_charts.py
   python scr/build_html.py
   ```
5. Откройте файл `Panko_NV_Tax_Debt_Analysis_RF.html` в любом современном браузере.
